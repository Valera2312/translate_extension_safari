# DeepL Translator for Safari (macOS)

Полноценное Safari-расширение для перевода веб-страниц с использованием DeepL API. Разработано специально для macOS с использованием Manifest V3, TypeScript и React.

## Основные возможности

- **Перевод всей страницы**: Запуск через контекстное меню (правый клик → «Перевести страницу»).
- **Режим оригинал/перевод**: Быстрое переключение между версиями через плавающую панель.
- **Поддержка языков**: Русский ↔ Английский (фиксированная пара).
- **Работа с динамическим контентом**: Корректная обработка SPA, AJAX и infinite scroll.
- **OCR для изображений**: Распознавание и перевод текста на картинках через Tesseract.js.
- **Умное кэширование**: Сохранение переведенных фрагментов для экономии лимитов API.
- **Обработка ошибок**: Retry-логика с экспоненциальной задержкой, понятные сообщения пользователю.
- **Индикатор прогресса**: Визуальное отображение статуса перевода.

## Требования

- macOS 12+ (Monterey или новее)
- Xcode 14+
- Safari 15+
- Node.js и npm
- Действующий API-ключ DeepL (Pro или Free)

## Установка и сборка

### 1. Установка зависимостей

```bash
npm install
```

Необходимые зависимости устанавливаются автоматически:
- `react`, `react-dom`
- `typescript`, `ts-loader`
- `webpack`, `webpack-cli`
- `copy-webpack-plugin`, `clean-webpack-plugin`
- `tesseract.js` (для OCR)

### 2. Настройка Xcode

1. Откройте проект в папке `native-mac-app/DeepL Translator.xcodeproj`.
2. В настройках проекта (**Signing & Capabilities**) выберите вашу Apple Team.
3. Убедитесь, что добавлен capability **Safari Web Extension**.

### 3. Сборка веб-части

Сборка копирует скомпилированные файлы в ресурсы Xcode:

```bash
npm run build
```

Для режима разработки с автосборкой:

```bash
npm run watch
```

### 4. Запуск в Safari

1. В Xcode нажмите **Run** (Cmd+R).
2. Откроется Safari. Перейдите в **Safari > Settings > Extensions**.
3. Найдите «DeepL Translator» в списке и включите его.
4. Подтвердите разрешение на работу со всеми сайтами.

## Использование

### Настройка API-ключа

1. Кликните по любой странице правой кнопкой мыши.
2. Выберите пункт **«Настроить DeepL»** (или аналогичный в меню расширения).
3. Введите ваш API-ключ DeepL.
   - Для бесплатного тарифа ключ заканчивается на `:fx`.
   - Для Pro тарифа — обычный ключ.
4. Нажмите «Сохранить». Система автоматически проверит ключ и покажет текущие лимиты.

### Перевод страницы

1. Откройте любую веб-страницу.
2. Кликните правой кнопкой мыши в любом месте страницы.
3. Выберите **«Перевести страницу»**.
4. Дождитесь завершения процесса (индикатор покажет прогресс).
5. Используйте плавающую панель для переключения между оригиналом и переводом.

### Перевод изображений (OCR)

1. Кликните правой кнопкой мыши по изображению на странице.
2. Выберите **«Распознать и перевести текст»**.
3. Текст будет извлечен, переведен и показан в уведомлении.

## Технические детали

### Manifest V3
Расширение использует современный стандарт MV3, обеспечивающий лучшую производительность и безопасность. Основной логикой управляет Service Worker (`background`), а взаимодействие со страницей происходит через изолированный Content Script.

### Работа с DeepL API
- **Chunking**: Тексты разбиваются на части до 4500 символов для соблюдения лимитов API.
- **Кэширование**: Хэш от текста сохраняется в `chrome.storage.local`. Повторные запросы не тратят лимиты.
- **Retry Logic**: При ошибках 429 (Too Many Requests) или сетевых сбоях выполняются повторные попытки с задержкой.
- **Безопасность**: API-ключ хранится только в защищенном хранилище браузера и никогда не передается в контент-скрипт напрямую.

### Обработка динамического контента
Расширение использует `MutationObserver` для отслеживания изменений в DOM. Это позволяет корректно работать с сайтами, подгружающими контент без перезагрузки страницы (SPA).

### Изоляция стилей
UI расширения рендерится внутри Shadow DOM, что гарантирует отсутствие конфликтов стилей с основным сайтом.

## Разрешения (Permissions)

В `manifest.json` запрошены следующие разрешения:

| Permission | Обоснование |
|------------|-------------|
| `contextMenus` | Добавление пункта «Перевести страницу» в меню правого клика. |
| `storage` | Локальное хранение API-ключа, кэша переводов и настроек. |
| `scripting` | Динамическая инъекция контент-скрипта на активную вкладку. |
| `activeTab` | Доступ к текущей вкладке только в момент действия пользователя. |
| `host_permissions` | Доступ к API DeepL (`api.deepl.com`, `api-free.deepl.com`). |

## Отладка

- **Консоли**: Логи контент-скрипта и background видны в **Develop > Show JavaScript Console** в Safari.
- **Нативная часть**: Логи Swift-кода доступны в окне отладки Xcode.
- **Source Maps**: Включены для удобства отладки TypeScript кода в Safari Web Inspector.

## Публикация и распространение

### Mac App Store
Для публикации в App Store необходимо:
1. Подписать приложение в Xcode действующим сертификатом разработчика.
2. Пройти модерацию Apple (App Review).

### Распространение вне App Store
Если вы распространяете `.app` файл самостоятельно:
1. Приложение должно быть подписано (**Code Signing**).
2. Должно пройти процедуру **Notarization** через Apple Developer Center, иначе macOS заблокирует запуск.
